# In der Lernplattform (LTI)

Abstimmbar lässt sich über den Standard **LTI 1.3** in Lernplattformen
einbinden — z. B. Moodle; Stud.IP, sobald dort LTI 1.3 verfügbar ist. Die
technische Einrichtung übernimmt einmalig die Administration Ihrer
Lernplattform (siehe [LMS-Einbindung (LTI 1.3)](../lti.md)). Danach können
Sie Abstimmbar in Ihren Kursen wie eine Aktivität verwenden.

## Einbinden

1. Fügen Sie in Ihrem Kurs eine Aktivität **„Externes Tool“** hinzu und wählen
   Sie die von der Administration angelegte Abstimmbar-Verbindung.
2. Über **„Inhalt auswählen“** öffnet sich die Auswahlseite von Abstimmbar:
   Wählen Sie ein **bestehendes Fragenset** des Kursraums oder legen Sie mit
   einem Titel ein **neues** an.
3. Speichern Sie die Aktivität. Sie können mehrere Aktivitäten anlegen — etwa
   eine je Fragenset.

## Was beim Öffnen passiert

**Für Sie als Lehrperson:**

- Sie sind **automatisch angemeldet** — ein separates Login entfällt. Je nach
  Einrichtung ist das dasselbe Konto wie bei der Anmeldung mit Ihrer
  Uni-Kennung.
- Beim ersten Öffnen aus einem Kurs legt Abstimmbar einen **Raum für den
  Kurs** an (Titel = Kurstitel) und verknüpft ihn dauerhaft mit dem Kurs. Jede
  Lehrperson, die Abstimmbar aus dem Kurs öffnet, wird Mitglied dieses Raums —
  so arbeiten Sie im [Team](team.md) am selben Raum.
- Sie landen direkt im ausgewählten Fragenset (bzw. im Kursraum) und können
  von dort präsentieren. Auf Ihrer Startseite trägt der Raum den Hinweis
  **„aus LMS“**.

**Für Studierende:**

- Sie werden **ohne Konto und anonym** auf die Teilnahmeseite des Kursraums
  geleitet — genau wie über QR-Code oder Raumcode. Abstimmbar erfährt aus dem
  LMS nichts über sie, was mit ihren Stimmen gespeichert würde.
- Sie sehen dort, was Sie in diesem Raum **gerade präsentieren** bzw. als
  Quiz-Block gestartet haben. Läuft gerade nichts, steht dort „Die Abstimmung
  hat noch nicht begonnen.“ — die Seite startet von selbst, sobald Sie
  beginnen.
- Ist die Aktivität mit einer **Lernkontrolle** verknüpft, landen Studierende
  direkt in dieser Lernkontrolle — vorausgesetzt, Sie haben sie
  [veröffentlicht](set-arten.md#lernkontrolle).
- Öffnen Studierende die Aktivität, bevor eine Lehrperson sie einmal geöffnet
  hat, erhalten sie den Hinweis, dass der Kurs noch nicht verknüpft ist.

!!! tip
    Öffnen Sie eine neue Aktivität einmal selbst, bevor Ihre Studierenden sie
    nutzen — dann ist der Kursraum angelegt.
