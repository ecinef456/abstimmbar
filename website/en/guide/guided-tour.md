# The guided tour

In just a few minutes, the **tour** shows you all the key features — right in
the interface, step by step, with highlighted controls and short
explanations.

## Starting it

- When you **sign in for the first time**, Abstimmbar offers the tour in a
  welcome dialog. You can start it there or skip it for now.
- Later, you can start it at any time via the **?** icon at the top right of
  the header → **“Start tour”**.
- The tour begins on the page you are currently on — for example directly
  in the results, if you start it from there.
- It adapts to your mode: in **expert mode** it also shows the expert
  features (e.g. AI shortcuts, bilingual content, archiving results).

## The example room

For the tour, Abstimmbar creates an **example room** when you first sign in
(“Example room – try things out”) — with a question set containing one
question of each type, and with **sample results** from two earlier runs.
The tour guides you through this room; it doesn't create anything itself and
doesn't change any of your content. If you have deleted the example room, the
tour offers to recreate it. Feel free to experiment in the example room and
delete it whenever you like.

## What the tour shows

1. Your room overview: creating your own room, archiving or deleting rooms.
2. The example room: question sets and their types (live poll, self-paced
   quiz, self-check), archiving results or deleting a set.
3. The set editor: adding a question and the list of question types.
4. Each question type individually in the editor — plus the settings every
   question has (random order, revealing the solution, time limit) and
   inserting images. If your example set contains a mind map or a four-field
   matrix (example rooms from October 2026 onwards), the tour introduces
   those as well.
5. Presentation mode: joining via QR code or room code, starting and
   stopping voting, switching between question, result and solution, moving
   to the next question and leaving the presentation.
6. The results: where to open them in the set, selecting earlier (archived)
   runs, exporting as CSV or deleting.

## Controls

- **“Next”** takes you to the next step, switching pages by itself if
  needed. You don't have to click anything — but you may: wherever the tour
  invites you to (e.g. opening “New question”), you can try it out right
  away.
- The tour is divided into sections (Rooms, Question sets, Question types,
  Presenting, Results); at the top of the window you can see where you are
  (e.g. “Question types · 3 of 11”). **“Back”** (or the ++arrow-left++ key)
  returns to the previous step, and **“Skip section”** jumps straight to the
  next section; ++arrow-right++ works like “Next”.
- Use **✕** or the ++esc++ key to end the tour. (If a menu is currently
  open, ++esc++ first closes just the menu.)
- If you leave the page in between, the tour **pauses**. A bar then appears
  at the bottom with **Resume** (continue on the current page),
  **Skip step**, **Skip section** and **End**.

!!! note "Statistics"
    Tour usage is recorded only as an anonymous daily count (how often it was
    started, completed or cancelled) — with no link to you personally.
