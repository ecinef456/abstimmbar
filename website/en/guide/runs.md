# Starting a run

How a question set plays out depends on its [type](set-types.md). This page
only covers how to start and end it. Every presentation of a live poll and
every self-paced quiz is saved as a separate **run**; you'll find the results
under [Results](results.md).

## Live poll and self-paced quiz

1. In the question set, click **Present**. Presentation mode opens for the
   projector and your room is opened to participants; the QR code and room
   code appear first (see
   [Inviting participants](inviting-participants.md)).
2. If there are already results, Abstimmbar asks what to do with them:
   **Keep counting** (into the same run), **Archive & restart** (the previous
   run is kept as an earlier run) or **Delete**. In simple mode, results are
   archived automatically when you present again on a different day.
3. **Live poll:** you go through it question by question, see
   [Presenting](presenting.md). In expert mode, a question's ▶ icon also
   starts **just that question**.
   **Self-paced quiz:** participants work on their own; the projector shows
   the time remaining and the answers per question. **End quiz** (++esc++)
   closes the quiz; it also ends by itself once the total time has run out.

The red **✕** in the presentation only **leaves** it. A run in progress is
ended via **End survey** or **End quiz** in the set's overview (see
[Leave or end](presenting.md#leave-or-end)).

## Self-check { #self-check }

Click **Publish**. The set then shows the **Permanent link** to copy (plus a
link straight to each individual question), a note on embedding it in your
LMS, the **number of attempts** with the share of correct answers, as well as
**Stop** (takes the link offline) and **Reset counter**. More under
[Self-check](set-types.md#self-check).
